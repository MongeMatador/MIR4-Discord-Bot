# ⚔️ MIR4 Discord Bot - Persistent Panel & Logging System

Bot profissional para gestão de clãs e controle de spots de Praça Fechada e Pico Secreto no MMORPG MIR4.

## 🚀 Tecnologias
- **Python 3.11+**
- **discord.py 2.3+**
- **SQLite + aiosqlite (WAL Mode + busy_timeout)**
- **aiohttp (Servidor HTTP para HealthCheck UptimeRobot)**
- **Docker & Docker Compose**

## 🔧 Instruções de Deploy
1. Suba as alterações para o seu repositório GitHub (`MongeMatador/MIR4-Discord-Bot`).
2. No painel do **Render** (`https://dashboard.render.com`), selecione o serviço `MIR4-Discord-Bot`.
3. Clique em **Manual Deploy** > **Clear build cache & deploy**.
4. Teste os comandos `/set_log_channel` e `/setup_painel` no Discord.
